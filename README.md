# Printer System (DSA Project)

### Prerequisites (สิ่งที่ต้องมีในเครื่อง)

1. C Compiler (GCC / MinGW-w64 / Clang)
2. CMake (เวอร์ชัน 3.10 ขึ้นไป)
3. Ninja (แนะนำสำหรับ Windows: `winget install Ninja-build.Ninja`)

### How to Run (วิธีรัน)

- **VS Code:** ลงส่วนขยาย CMake Tools แล้วกด `F7` เพื่อ Build และ `Shift + F5` เพื่อ Run
- **CLion:** เปิดโฟลเดอร์โปรเจกต์แล้วกดปุ่ม Run สีเขียวได้ทันที
